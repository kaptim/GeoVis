# Visual Geolocation on Microcontroller Units

This is the TensorFlow implementation of my final project for the course "Machine Learning on Microcontrollers" at ETH Zurich. The goal was to infer the location of an image based on its contents on a microcontrolling unit such as the Sony IMX500. I used the [OSV-5M](https://osv5m.github.io/) dataset to train and test the models.
